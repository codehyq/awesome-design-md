## 已修正的问题

- Windows 默认 Python 服务曾将 .js 返回为 text/plain，阻止 ES module；新增本地 Node 服务，明确设置 MIME。
- 同一天的账单按字符串 ID 排序不能表达新增顺序；改为按日期稳定排序，保留插入次序。
- 首页截取最近流水时，日期汇总曾跟随截取范围缩小；改为该日期的完整支出。
- 中等宽度下介绍与手机并排可能溢出；601–740px 改为单独展示手机。
- 小屏品牌分类入口改为可横向滚动访问。
